# VANTAGE 2.0 — правила проекта

Личный аналитический инструмент по Dota 2. Только русский язык. Тёмная тема, светлой нет.

## Железные правила

1. Код без комментариев. Имена функций и переменных объясняют сами себя.
2. Ответы пользователю без воды. Списком, по делу.
3. Один accent-цвет на весь сайт: `--accent` (циан). Никаких вторых акцентов.
4. Одна шкала скруглений: 8 / 12 / 16 / pill. Смешивать по своему усмотрению нельзя.
5. Никаких em-dash (—) и en-dash (–) в видимом тексте. Только дефис.
6. Иконки — только `@phosphor-icons/react`, strokeWidth един по проекту. SVG-иконки руками не рисуем.
7. Числа — только моноширинным (`--fm`), `font-variant-numeric: tabular-nums`.
8. Любая анимация обязана иметь причину: иерархия, обратная связь, смена состояния. Анимации «чтобы красиво» запрещены.
9. `prefers-reduced-motion` обязателен везде, где есть движение.
10. Каждый экран имеет 4 состояния: loading (скелетон по форме контента, не спиннер), empty, error, success. Скелетон обязателен, не «Загрузка...».
11. Ключ Stratz никогда не попадает в репозиторий. Только `.env.local` и серверный прокси.
12. Перед отдачей билда — `npm run build` и `npm run test` должны проходить. Неработающие билды не отдаём.

## Запрещено (AI-tells)

- Секции-эйрбоу с номерами (`01 / ОБЗОР`)
- Декоративные цветные точки перед пунктами
- Разделитель `·` больше одного на строку
- Фейковые точные числа без источника
- Прогресс-бары с залитым фоном-треком там, где хватит числа
- Однотипные прямоугольные плашки подряд (прямая претензия заказчика к прототипу)

## Что нельзя менять без спроса

- Название VANTAGE
- Цветовая палитра (можно расширять оттенками, но не менять базу)
- Существующие маршруты: `/`, `/player/:id`, `/match/:id`, `/heroes`, `/heroes/:id`, `/team/:id`, `/esports`, `/compare`, `/search`

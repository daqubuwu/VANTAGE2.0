# Архитектура VANTAGE 2.0

## Решение по стеку

| Слой | Выбор | Почему |
|---|---|---|
| Сборка | Vite 6 | Быстрый дев-сервер, тривиальный деплой |
| Язык | TypeScript strict | На 268 КБ логики без типов правки становятся лотереей |
| UI | React 19 | Экосистема, TanStack Query, простое переиспользование блоков |
| Роутинг | React Router 7 (BrowserRouter) | Vercel умеет rewrite, хеш в URL больше не нужен |
| Стили | Tailwind v4 + CSS-переменные | Токены прототипа переносятся 1:1 в `@theme`, плотные сетки собираются быстрее |
| Данные | TanStack Query + persist в IndexedDB | Даёт авто-рефетч, stale-while-revalidate, дедупликацию и офлайн-кэш из коробки |
| Графики | Свой слой на SVG | Recharts даёт «библиотечный» вид, а нужные графики специфичны и уже написаны в прототипе |
| Иконки | @phosphor-icons/react | Единое семейство, есть игровые метафоры |
| Шрифты | Onest + JetBrains Mono, самохост | `<link>` на Google Fonts блокирует рендер |
| Тесты | Vitest | Только чистая логика: скоринг, агрегации, парсер матча |
| Хостинг | Vercel | Нужны serverless-функции под прокси Stratz, бесплатно |

Отказ от vanilla JS осознанный: пункт 2.1 анкеты — переписываем с нуля, а прототип уже упёрся в потолок сопровождаемости одного файла.

## Структура

```
src/
  app/            роутер, провайдеры, layout, error boundary
  pages/          по одному файлу на маршрут, только композиция
  features/       смысловые блоки: draft/, match/, player/, hero/, meta/, esports/
  shared/
    api/          клиенты OpenDota и Stratz, схемы, нормализация
    cache/        IndexedDB persister, политики свежести
    lib/          чистые функции: скоринг, агрегации, форматтеры
    ui/           дизайн-система: Card, Stat, Bar, Tooltip, Skeleton, Tabs
    charts/       SVG-примитивы: Line, Area, Heatmap, Timeline, Sparkline
  styles/         токены, база
api/
  stratz.ts       serverless-прокси, прячет ключ
```

Правило: `features/` не импортирует из `pages/`, `shared/` не импортирует ни из чего выше.

## Данные

### Источники

| Что | Источник | Почему |
|---|---|---|
| Матчи, профили, герои, предметы | OpenDota REST | Без ключа, щедрые лимиты, полный разбор распарсенных игр |
| Прокачка способностей, лейнинг, детали таймингов | Stratz GraphQL | У OpenDota этих полей либо нет, либо они пустые |
| Про-сцена, live-матчи | OpenDota + Stratz | У OpenDota календарь беднее |
| Иконки героев и предметов | Steam CDN | Уже используется в прототипе |

### Политика свежести (из ответа 5.5)

| Данные | staleTime | Хранение |
|---|---|---|
| Матч (завершённый, распарсенный) | вечно | IndexedDB, не протухает |
| Матч (не распарсенный) | 5 мин | IndexedDB |
| Профиль и последние матчи игрока | 2 мин | IndexedDB |
| Live-матчи | 30 сек | только память |
| Мета героев, винрейты | 12 часов | IndexedDB |
| Константы: герои, предметы, способности | до смены патча | IndexedDB |

Авто-обновление вместо кнопки: `refetchOnWindowFocus` для профиля и live, фоновый рефетч по `staleTime`. Ручная кнопка остаётся как принудительный сброс.

### Ключ Stratz

Клиент никогда не видит ключ. Запрос идёт на `/api/stratz`, функция на Vercel подставляет `Authorization` из переменной окружения. Локально то же самое через `vercel dev`.
Локальный файл `.env.local` в `.gitignore`. В репозиторий уезжает только `.env.example`.

## Производительность (ответы 8.1-8.3)

- Страница игрока рисуется в три волны: профиль, затем последние 20 матчей, затем агрегаты по героям. Каждая волна показывает свой скелетон.
- История матчей грузится по 20 с догрузкой при скролле через IntersectionObserver.
- Бюджет: первый осмысленный экран меньше 1 сек из кэша, полная страница до 5 сек по холодному запросу.
- Тяжёлые агрегации (500+ матчей) считаются в Web Worker, чтобы не морозить прокрутку.

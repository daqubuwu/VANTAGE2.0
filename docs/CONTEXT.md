## Грабли, на которые уже наступали

**`vercel dev` ломает Vite.** Падает на разборе `index.html` с ошибкой import-analysis. Использовать только `npm run dev`, прокси Stratz в деве обслуживает плагин из `vite.config.ts`. Не предлагать `vercel dev` снова.

**Функция в `api/` должна быть на JS, не на TS.** Vercel собирает её своим компилятором, подхватывает корневой `tsconfig.json` и падает на `Cannot find type definition file for 'node'` и `'vite/client'`. Переписана в `api/stratz.js`.

**Базовые сбросы стилей должны лежать в `@layer base`.** Без слоя они перебивают все утилиты Tailwind v4, и кнопки рендерятся голым текстом. Уже чинилось, не сломать снова.

**Кэш TanStack Query в IndexedDB падал с `DataCloneError`.** Причина: собственный `shouldDehydrateQuery` пропускал незавершённые запросы, а в них лежит Promise. Лечится комбинацией с `defaultShouldDehydrateQuery`, см. `src/main.tsx`.

**Иконки рангов лежат не на Steam CDN**, а на `www.opendota.com/assets/images/dota2/rank_icons`. Со Steam приходит 404.

**У облачного контейнера нет доступа к `api.opendota.com`.** Живые данные там не проверить. Проверка визуала — через `scripts/shot-mocked.mjs`: поднимает сборку в headless Chromium, подменяет запросы фикстурами, снимает скриншот и собирает ошибки консоли. Этим уже поймано два бага. Перед отдачей билда прогонять `npx tsc -b --noEmit`, `npx vitest run`, `npx vite build` и скриншот.

**Пуш из облачного контейнера блокирует git-прокси**, если репозиторий не в источниках сессии. Токен не помогает. Если в новой сессии репозиторий подключён источником, пушить можно самому.

## Договорённости по продукту, которые легко нарушить

- Никакого LLM в рантайме. Всё считается статистикой и эвристиками в браузере. Тексты разбора собираются из правил с подстановкой чисел, фраза без числа не показывается.
- Оценка игрока обязана меняться при движении ползунка времени в матче. Метрика, у которой нет ряда по минутам, помечается «по итогу» и выпадает из веса грани.
- Заглушек с придуманными числами не бывает. Нет данных — прочерк и объяснение.
- На странице игрока ровно 20 матчей, полный список с догрузкой по скроллу живёт на вкладке «Матчи».
- Палитра и название VANTAGE неприкосновенны.
- Палитра по Ctrl+K удалена намеренно, не возвращать.
- Отклонено заказчиком: разбор лейнинга по минутам, план тренировки на 10 игр, прогноз исхода матча, уведомления и отслеживание друзей.
